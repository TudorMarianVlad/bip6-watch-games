## How to use these scripts

One creature per **new Gemini chat**, and paste the script as one message.

- **Brand-new creatures** (1–4, 11–20, and the first form of each line): attach two of your existing
  creatures as a **style reference**: `Wristlings\art\sprig.png` and `Wristlings\art\frostfang.png`
  work well (one cute, one fierce).
- **The two lines:** make them in this order: **first form**, then **final form** (attach the first
  form), then **middle form** (attach both, like the middle-evolution scripts).
- Send the results to Claude (any names, .jfif is fine), or save them as `Wristlings\art\<id>.png`.

Every script ends with the full style guide (look, lines, shading, eyes, pose, background), fitted to the
creature: cute eyes and blush for first forms, fiercer eyes for final forms, a lavender glow edge for
shadow creatures. There is no need to paste the style guide first.
