# Wristlings: middle evolutions (Gemini scripts)

Every evolution line now has three stages. The middle form is the **teenager**: still clearly the
first form, just a little older and bigger, with two or three changes that point toward the final
form. The big, scary look stays saved for the final form.

| Line | Evolves at |
|---|---|
| first form → **middle form** | the old level (12–16) |
| **middle form** → final form | Lv 28 (Kindlepig's line also needs 100+ weekly PAI for this step) |

## How to use these scripts

Do one creature per **new Gemini chat** (in an old chat Gemini copies its earlier pictures).

1. Attach **two images**, in this order:
   - **Image 1:** the first form, `Wristlings\art\<first>.png`
   - **Image 2:** the final form, `Wristlings\art\<final>.png`
2. Paste the creature's script below. It already includes the pixel-art style, so there is no need to
   paste the style guide first.
3. If the result still looks too much like the final form, answer:
   > Too close to image 2. Start again from image 1 and change only the 3 things in my list.

   If it looks exactly like image 1, answer:
   > Too similar to image 1. Keep everything, but make the 3 changes in my list clearly visible.
4. Save the one you like (any file name, .jfif is fine) and send it to Claude, or save it as
   `Wristlings\art\<middle id>.png` yourself.

Every script uses the same shape:

> I'm attaching 2 pixel-art sprites of the SAME creature from my monster-collecting game. Image 1 is
> its baby form, image 2 is its final adult form. Draw the MIDDLE stage between them: the same
> creature as image 1, just a bit older and a little bigger. It must still look almost like image 1:
> same face, same colours, same body shape, same cute eyes, same pixel-art style and dark outline.
> Change ONLY these 3 things: ... Do NOT copy image 2: no adult proportions, no armour, nothing scary;
> image 2 only shows the direction it grows in. STYLE: ... (the full style guide: look, lines,
> shading, eyes, a glow edge for shadow creatures, pose, background).
